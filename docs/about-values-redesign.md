# About values redesign

Implemented the approved four-principle layout: Integrity, Accountability, Quality and Continuous Improvement. Short statements replace the six verbose cards.

The warm-white section uses open editorial rows, navy vector icons, orange nodes and a fine vertical line. Desktop rows place descriptions alongside titles; tablet and phone layouts place descriptions underneath. The centred heading and spacious layout follow the preceding vision and mission section.

Content remains server-rendered text with semantic headings and a list. No photos, calls to action or client-side animation were added. Other About sections are unchanged.

Validation: ESLint and production build passed. Browser checks passed at 1366, 1024, 768, 390 and 320 pixels, with four visible principles, aligned nodes, no horizontal overflow and no page errors. The production SEO audit checked 88 pages and 140 images with zero errors or warnings.
